# Tap to Flip

Choose a key to reveal answers in Anki—including **Command (⌘) alone on macOS**.

## Install

1. Download the add-on from [Releases](https://github.com/cobeycobb/Tap-to-Flip/releases/latest).
2. In Anki, go to **Tools → Add-ons → Install from file…** and select it.
3. Restart Anki.

## Use

Open **Tools → Tap to Flip Settings…**, click **Choose key…**, press your preferred key, and **Save**.

Tap and release that key to reveal an answer. Command is selected by default. Shortcuts such as ⌘+C still work, and tapping Command won't grade the card.

Tested on Anki 25.09.4 for macOS.
